# 固定元素资产制作与验收规范

> 适用：后续为侧边栏固定元素补充真实 GLB、PNG、Shader、音效或缩略图时。

## 1. 资产命名

```text
<category>_<element>_<variant>_<lod>.<ext>
```

示例：

- `furniture_table_wood_lod0.glb`
- `game_chest_iron_lod1.glb`
- `fx_firefly_swarm_mote.png`
- `toy_tank_toy_lod0.glb`

目录 ID 使用稳定的点号命名，例如 `furniture.table`、`fx.firefly_swarm`。文件名可换版本，目录 ID 不因换模型而改变。

## 2. GLB/GLTF 要求

- 单位：米；Y 轴向上；前向遵循项目现有 `-Z`；
- 原点：可摆放物体放在底部中心；漂浮物放在几何中心；
- 变换：导出前应用 scale/rotation，实例缩放留给编辑器；
- 材质：优先 PBR，避免无法在移动端使用的复杂节点；
- 贴图：优先 WebP/PNG，尺寸默认 1024，必要时提供 512 低配版本；
- 碰撞：提供简单 Box/Sphere/Capsule 或独立 collider，不用高模三角面直接做实时碰撞；
- 动画：开合/旋转/悬浮等动作要有明确 clip 名称；
- 版本：同一元素至少记录 `element_version` 和资源版本，不能静默替换已放置实例。

## 3. 粒子/Shader 要求

- 所有粒子提供 `maxCount`、默认 count、低配 count；
- 提供 start/stop/reset 三个生命周期入口；
- 透明/Additive 效果必须验证深度写入、排序和叠加；
- 粒子元素必须有空间范围，不能默认覆盖整个场景；
- 飞掠元素必须有速度上限、同时实例上限和路径解除机制；
- 移动端低配模式优先降低数量和贴图尺寸，不直接隐藏所有反馈。

## 4. 缩略图和卡片

每个固定元素至少需要：

- 256×256 透明或浅色背景缩略图；
- 16×16 或 SVG 图标语义；
- 中文名、英文/技术名、标签；
- 默认落点、碰撞类型、交互 Profile；
- 失败占位图，不能因为缩略图加载失败导致无法添加。

缩略图只服务侧边栏展示，不作为场景实例的运行时资源引用。

## 5. 资产验收表

| 检查项 | 通过条件 |
|---|---|
| 命名 | 文件名和目录 ID 稳定、无空格、可追踪版本 |
| 原点 | 按目录的 pivot 规则放置后不悬空、不陷地 |
| 尺寸 | 默认尺寸符合场景比例，至少有一个可调缩放范围 |
| 材质 | 编辑器预览和 Runtime 颜色/透明度基本一致 |
| 碰撞 | 不使用高模实时碰撞，交互范围可解释 |
| 性能 | 记录三角面、贴图、材质、Draw Call、粒子上限 |
| 互动 | 目录声明的 Profile 可触发、可停止、可重置 |
| 降级 | 没有外部文件或加载失败时仍显示占位并给出日志 |
| 授权 | 记录来源、许可证、允许的项目范围和可发布范围 |
| 可删除 | 删除项目实例不影响目录和其他场景引用 |
