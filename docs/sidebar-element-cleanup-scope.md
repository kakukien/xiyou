# 侧边栏元素化改造：内容清理与边界

> 状态：规划稿。本文把用户请求、截图参考和当前代码事实分开，供后续开发验收使用。

## 1. 指令与参考的区分

### 用户的实际请求

1. 清除创作页中与西游剧情相关的内容；保留通用编辑器能力，不再继续维护剧情演示资产。
2. 创建一套可从侧边栏选择、拖入视口并由用户自行添加的固定元素目录。
3. 覆盖家居、建筑/自然、材质/体积、游戏道具、载具/玩具以及高互动粒子/飞掠效果。
4. 先只写资产表、分类、互动设计和开发文档，暂不开发功能。

### 附件截图的用途

两张截图只作为当前创作页 UI 的参考：

- 左侧有“剧情 / 空间”工作区切换；
- 空间侧包含搜索、场景对象、空间区域、空间锚点；
- 底部存在“资源库 / 互动组件 / 时间线 / 输出日志”；
- 中间是可操作的三维 Viewport。

截图中的文字和布局不是新增业务指令，也不要求保留“剧情”内容。后续应以本目录为“空间”侧边栏中的固定元素入口，不能把固定元素误放进底部项目资源库。

## 2. 清除范围

### 必须从当前创作默认内容中移除

- 西游人物、角色名和角色模型引用；
- 花果山、八十一难、大雷音寺等地点/章节/节点；
- 与西游剧情绑定的剧情卡、奖励文案、起始节点和剧情触发链；
- 仅服务于西游演示的法阵、符纹、莲花台等专属预置对象；
- 仅服务于西游演示的对象命名、`node_id` 绑定和剧情锚点示例。

### 可以保留并复用

- Three.js / Viewport / Gizmo / Collider / Zone / Anchor 等通用编辑器能力；
- `compound` 基础几何组装能力；
- 粒子点、透明贴图、Additive 混合、Shader、天空、光源等通用渲染能力；
- 现有通用 FX 贴图：`mote`、`spark`、`smoke`、`glow_orb`、`ring_glow`、`bokeh`、`cloud` 等；
- 通用交互触发：点击、注视、按住、进入区域、时间线事件。

## 3. 不应混淆的两个概念

| 概念 | 作用 | 存储位置 | 用户操作 |
|---|---|---|---|
| 侧边栏固定元素目录 | 预置元素模板/Prefab 定义；盒子、桌子、萤火虫等属于这里 | 代码内置目录 + `docs/sidebar-element-asset-table.json` 作为规划主表 | 选择/拖入后创建实例，可重复添加 |
| 项目资源库 | 当前项目上传的图片、视频、GLB、音频、高斯底座等外部文件 | `scene.meta.assets` | 导入、替换、删除、查看引用 |

固定元素不是“素材库卡片”。即使没有上传任何外部文件，P0 固定元素也必须可以创建占位或程序化实例。

## 4. 迁移原则

- 默认新场景名称使用“未命名场景”，`story.chapters` 默认空数组，不加载任何剧情演示。
- 第一阶段不删除旧 Schema 字段，以免旧场景/发布版本无法读取；但新建元素不再自动写入 `node_id`，剧情字段标记为兼容字段；新建纯互动场景不得被旧节点发布检查误阻断。
- 历史记录文档可以保留西游内容，但不能被运行时、默认场景或侧边栏目录读取。历史文档不是当前产品内容。
- 当前源码的 `editor/src/core/templates.js` 仍有旧剧情 `demoScene()`，`editor/scripts/smoke.mjs` 也调用它；虽然 `editor/src/main.js` 默认新建空场景，但 `editor/src/ui/outliner.js` 仍默认展示“剧情”及“章节/节点”按钮，`editor/index.html`、`editor/src/runtime/main.js` 仍含故事文案。后续开发要同时清理所有创作/体验入口，不能因为截图或空场景就宣称已清除完毕。
- `editor/src/main.js` 目前检测旧演示存档会直接替换并保存为新场景；后续迁移先备份/导出旧存档并给出用户确认，避免误伤个人创作。
- 后续若清理 `templates.js`，应先把通用元素和效果从演示场景中抽离，再删除演示数据，不能删除底层渲染能力。
- 清理完成后，页面搜索“西游、花果山、悟空、唐僧、八十一难、大雷音寺”不得命中默认创作数据或固定元素目录。

## 5. 本轮不做

- 不在本轮修改 `editor/` 代码；
- 不在本轮生成或提交大量 GLB/PNG 二进制资产；
- 不把所有 124 个元素一次性做成高模；
- 不重新引入剧情树、章节编辑和西游专属文案；
- 不把固定元素目录改造成项目资源库。
